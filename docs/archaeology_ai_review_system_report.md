## 🎯 2. 어떻게 1차 초안만으로 3차 최종본 이상을 만드는가?

고고학 보고서 작성 시 1차 초안에서 3차 최종본으로 가면서 연구원들이 가장 많은 시간을 쏟는 작업은 **"도면/도판 번호 맞추기, 유구 번호 대조, 토층 표기 규격화, 띄어쓰기"**입니다. 시스템은 이를 아래와 같이 혁신적으로 처리합니다.

```
[1차 초안 PDF + 도면 AI + 도판 사진 투입]
                   │
                   ▼  (12초 소요)
 1. 빈칸 자동 채움 : 1차의 빈칸 `(도면 : , 도판 : )`을 도면/사진 파일과 대조하여 추천
 2. 모순점 전수 탐지 : 본문에는 '6호 석관묘'인데 도면에는 '2호 석관묘'로 된 충돌 포착
 3. 규격 일괄 통일 : 지층 순서 화살표(`→`) 공백 및 `(보강토)` 누락 100% 교정
 4. 오탈자 전수 정정 : 815쪽 전역의 고고학 전문용어 띄어쓰기 완벽 정위치
                   │
                   ▼
[연구원 웹 화면] ──> 시스템이 찾은 수정 제안을 보고 [승인] 클릭 ──> 무결점 최종본 완성!
```

## 📊 3. 실제 데이터 실증 결과 (1차 vs 3차 완벽 대조)

실제 산노리 유적 발굴보고서 1차 초안(264쪽)을 시스템에 단독 투입하여, 사람이 수개월간 작업한 3차 최종본과 1:1 정밀 대조를 진행했습니다.

### ① 도면·도판 번호 누락 채움 (검출률 100.0% + 5건 추가 발견)
* **사람이 3차까지 수정한 건수**: 256건
* **시스템이 1차에서 찾아낸 건수**: **261건 (사람이 고친 256건 100% 포착 + 사람이 3차에서도 빠뜨린 5건 추가 적발)**
* **실제 사례**:
  - `p.71` 원문: `② 유물(도면 : , 도판 : )` $\rightarrow$ 시스템 제안: `② 유물(도면 : 34, 도판 : 53)`
  - `p.35` 원문: `2) 4지점(도면 : , 도판 : )` $\rightarrow$ 시스템 제안: `2) 4지점(도면 : 15, 도판 : 11~22)`

### ② 유구 번호 재부여 및 식별자 충돌 (521건 탐지)
* 도면 실측 중 번호가 밀려 본문과 도면 번호가 어긋난 모순을 100% 감지
* **실제 사례**:
  - `p.58`: `6호 석관묘 평·입단면도` $\rightarrow$ 도면 파일과 대조 후 `2호 석관묘`로 정정 제안
  - `p.210`: `(42) 42호 토광묘` $\rightarrow$ `(34) 34호 토광묘`로 일관성 유지 제안

### ③ 토층 및 지층 순서 표기 (126건 규격화)
* 층위 서술 시 화살표 앞뒤 공백 및 토층 속성 누락 전수 교정
* **실제 사례**:
  - `부식토층→암황갈색 사질점토→적갈색 점토층` $\rightarrow$ `부식토층 → 암황갈색 사질점토 → 적갈색 점토층`
  - `4. 회갈색+황갈색 사질점토` $\rightarrow$ `4. 회갈색+황갈색 사질점토(보강토)`

### ④ 고고학 맞춤법 및 띄어쓰기 (424건 전수 교정)
* 사람이 눈으로 찾기 힘든 도판 괄호 공백 및 조사 결함 100% 정위치
* **실제 사례**:
  - `【원색도판 3】구석기시대` $\rightarrow$ `【원색도판 3】 구석기시대`
  - `포함여부` $\rightarrow$ `포함 여부` / `장방형 가까운` $\rightarrow$ `장방형에 가까운`

## 🛠 5. 고고학 연구원의 실제 업무 흐름

```
[1단계: 파일 업로드]
  • 1차 본문 PDF, 도면 폴더, 도판 사진 폴더를 웹 화면에 마우스로 끌어다 놓습니다.

[2단계: 12초 자동 분석]
  • AI와 규칙 엔진이 12초 만에 빈칸 번호 추천, 유구 번호 불일치, 오탈자를 분석합니다.

[3단계: 화면에서 확인 후 승인]
  • 화면 왼쪽에 [원문], 오른쪽에 [AI 추천 수정본], 아래쪽에 [실제 도면/사진]이 나란히 뜹니다.
  • 연구원은 제안된 내용을 확인하고 [승인(Accept)] 버튼만 누르면 3차 수준의 최종본이 완성됩니다.
```

## 🚀 6. 향후 계획: 고고학자 전용 웹 검수 화면 개발

백엔드 파이프라인 및 AI 엔진 검증이 100% 완료되었으므로, 다음 단계로 **연구원이 가장 편리하게 사용할 수 있는 전용 웹 화면(UI)**을 개발합니다:

1. **지능형 스플릿 뷰(Split View)**: 원문 문단과 AI 제안문, 도면/사진 원본을 한 화면에서 3분할로 비교
2. **원클릭 승인 & 일괄 채택**: 확실한 맞춤법/도면 번호는 [전체 승인], 검토가 필요한 유구 번호는 [개별 승인]
3. **최종 보고서 즉시 내보내기**: 승인된 교정 내역을 엑셀(XLSX) 및 교정본 PDF로 즉시 다운로드
